# Медиакоми — угадай цену квартиры в республике Коми

Мобильная игра по реальным объявлениям Авито: игрок смотрит фотографии квартиры,
ставит свою цену бегунком и узнаёт, насколько он близок к реальной цене.

## Структура

- `index.html` — единственная страница (3 экрана: старт, раунд, итоги)
- `styles.css` — стиль в духе hse.ru (#012D6E), mobile-first
- `game.js` — логика игры, галерея, бегунок, балльная система
- `data.js` — данные объявлений, фото уже на локальных путях `img/…`
- `img/` — оптимизированные фотографии (до 900 px, JPEG ~65%)
- `kvartiry_komi.csv` — исходная выгрузка объявлений Avito

## Правила и баллы

- 10 раундов по одной квартире.
- Ошибка до 5% → 10 баллов, до 10% → 8, до 20% → 6, до 35% → 4, до 50% → 2, до 75% → 1, больше → 0.
- Максимум 100 баллов.
- Итоговый типаж: **Жадный студент** (ставки в основном ниже реальных цен),
  **Адекватный квартирант** (большинство оценок в пределах 10%),
  **Транжира** (ставки в основном выше).

## Обновление данных

```bash
python3 gen_data.py          # перечитывает kvartiry_komi.csv, отбирает активные объявления
python3 download_images.py   # скачивает фото в img/, сжимает и переписывает data.js
```

В `data.js` попадают только объявления с загруженными фотографиями (активные).

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `mediakomi`).
2. Загрузите файлы:
   ```bash
   git init
   git add index.html styles.css game.js data.js
   git commit -m "Медиакоми: игра"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/mediakomi.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Через минуту игра будет доступна по адресу
   `https://<ваш-логин>.github.io/mediakomi/`.

Никакой сборки не нужно — это чистый HTML/CSS/JS.
